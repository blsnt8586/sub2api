## 当前版本的具体改动

原版在快速成长后直接通关，捕食者基本使用同一套追逐行为。新版本默认选中「猎手挑战」，并保留「轻松开吃」：

1. **限时黄金鱼潮**：开局六秒后出现六尾金鱼，11 秒内全部吞食奖励 500 练习分并恢复一格生命；超时鱼群离开，未完成不发整群奖励。之后间隔 16 秒再出现，引导玩家临时改变路线。
2. **可读的猎手攻击**：开局十八秒后进入海域。巡游 → 预瞄 → 锁定路线 → 冲锋 → 疲惫，每次预瞄末尾至少留半秒固定路线。玩家可以横移躲开或消耗冲刺体力穿过；疲惫时冲刺撞尾获得奖励和成长，同一窗口只结算一次，奖励 300 分与 18 成长质量。
3. **最终咬尾战**：成长到最后形态进入决战。冲锋结束后尾部开放 3.6 秒反击窗口，三次有效咬尾才获胜。成长不会重置已消耗的 Boss 弱点次数。决战时普通捕食者退场，避免随机敌群掩盖可读的冲锋与反击。
4. **重玩目标**：一星为完成挑战；150 秒内完成再加一星；保留至少两命且惊险闪避与咬尾合计至少五次，再加一星。成绩依旧是本地会话练习记录。

黄金鱼潮的数量 / 时限、猎手时序、咬尾条件和星级条件是本项目的设计选择，不宣称它们是上述游戏的原版规则。未引入付费升级、额外按键或新的持久化经济系统。

## 深海远征的玩法落地（2026-10-21）

为了让远征不变成“只把鱼放得更大”，当前实现把深度、收集和陪伴事件分开：玩家可以在最终进化后继续下潜，水层会从日光浅礁推进到暮光水域和幽蓝深渊；图鉴发现与三枚遗物提供短路线目标，巨兽伴游则提供限时的六光晶收集目标。巨兽本身不会攻击，也不能被吞食，避免把视觉上的尺度差异误读为普通猎物。

深海猎食鱼按栖息水层生成，浅层不会突然出现蝰鱼或吞鳗；皇带鱼、蝠鲼、鲸鲨、蓝鲸作为温和巨兽在海域中出现。遗物、光晶和生物发现均做一次性结算，伴游超时不会发放完成奖励。远征模式最终形态的额外体型增长有上限，实体数量也有边界；正常吞食得分仍可随持续游玩累积。

验证覆盖 23 种图鉴条目、三档水层、深海生物栖息边界、温和巨兽碰撞关系、三枚遗物、六枚光晶路线、超时与重置隔离，以及页面模式切换。页面使用本地原创位图和 Canvas 渲染，不需要 Unity、Three.js 或运行时外部资源。
