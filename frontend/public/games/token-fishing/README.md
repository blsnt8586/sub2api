# TOKEN 垂钓：2D 海湾探索

以可见鱼群、鱼饵食物链与装备成长为核心的原创 2D 钓鱼小游戏。参考 Cat Goes Fishing 的侧面水下视野与小鱼钓大鱼思路，使用原创角色、鱼类和场景美术。

## 玩法

- 没有倒计时。点按海面选择落点并抛竿；水下拖动可控制鱼钩，点按主按钮切换收线 / 松线。鱼主动追逐匹配的鱼饵，咬钩后自动开始收线。
- 银叶小鱼 / 太阳蓝鳃吃基础饵；青纹鲈 / 丹霞锦鲤吃小鱼；远洋蓝鳍 / 月光金翅吃中鱼。捕食者也可能吞下仍挂在钩上的小鱼。快速收线会吓跑锦鲤。
- 上岸后选择卖出，或者将小 / 中型鱼装成下一竿的一次性活饵。基础饵无限，活饵随本竿消耗。大型鱼只可出售。
- 鱼线升级依次解锁 17.5 / 29.5 / 40.5 / 51 米，鱼竿升级承重为小 / 中 / 大。超过承重时张力迅速升高，松线可缓解，持续硬拉会断线。适配的鱼竿仍需留意大鱼的间歇挣扎。
- 六种鱼的图鉴和三个自动发奖目标，引导玩家从浅水探索深水。游戏币仅供装备消费，不兑换 API 额度。

| 输入 | 操作 |
| --- | --- |
| 鼠标 / 触屏 | 海面点按抛竿，拖动转向；按钮切换收线 / 松线，左右按钮微调 |
| 键盘 | 左右 / A D 转向，空格抛竿 / 收线 / 松线，P 暂停；Esc 退出沉浸模式 |
| 标准手柄 | 方向键 / 左摇杆横向转向，A 主操作 / 出售，X 留作鱼饵；菜单暂停，暂停后 A 继续；上下切换港口标签，B 退出沉浸模式 |

## 美术来源

通过用户授权的已配置 Codex provider，使用 imagegen 技能 bundled CLI 调用 `gpt-image-2`（high quality）生成。原图在忽略目录 `output/imagegen/fishing-2d/`，发布包只使用本地 WebP，无远程图片依赖或运行时凭据。

| 提示词 | 输出 |
| --- | --- |
| [prompts/cove.txt](prompts/cove.txt) | 1536 × 1024 海湾水下剖面，转 `cove.webp`；另缩放为游戏库 `../library/fishing.webp` |
| [prompts/sprites.txt](prompts/sprites.txt) | 1536 × 1024 六鱼图集，逐格裁切、去纯品红底，导出六个带透明通道的 `*-sprite.webp` |
| [prompts/angler.txt](prompts/angler.txt) | 1024 × 1024 原创橘猫钓手，去品红底并裁切为 `angler.webp` |

Canvas 按鱼群真实坐标绘制，鱼尾分段摆动、追饵 / 捕食、鱼钩弧线、鱼线、鱼竿、溅水与气泡由代码驱动。`engine.ts` 负责模拟与存档校验，`renderer.ts` 负责渲染，`FishingScene.vue` 负责素材与画布生命周期。素材载入失败可重试；离开时取消动画并释放观察器。无需 WebGL / Three.js。页面支持浅色、深色、手机和沉浸模式。

## 进度与验证

进度按登录账号 ID 隔离，使用 `token-fishing-v1:<id>` 保存在当前浏览器 localStorage：游戏币、装备、图鉴、任务、累计钓获、待处理渔获和岸边已装活饵。待售渔获恢复后只可结算一次。页面每 5 秒及交易 / 上岸 / 暂停 / 离开时存档；离开水下对局后重新载入从岸边继续，水下活饵消耗，不赠送未上岸的鱼。清理浏览器数据会清空进度，暂不支持跨设备同步。存储失败时明确提示，仍可玩当前会话。

游戏库统计只记录本次进入游戏后新增的销售 / 任务收益，使用对局 ID 去重，避免将历史存档收益重复计入。大厅会话统计刷新清空，垂钓进度独立保留。所有数据都是本地练习数据，不进入计费系统。

引擎测试覆盖追饵、鱼饵匹配、捕食、锦鲤习性、断线 / 松线、出售幂等、鱼饵与装备升级、任务唯一奖励、存档校验与恢复；页面测试覆盖输入、自动暂停、素材重试、用户隔离、存档和新增收益记分。

## 出航玩法：寻宝、闪避与委托（2026-10-20）

可切换「鱼饵钓鱼」与「磁钩寻宝」两种装备，默认使用鱼饵钩。磁钩不吸引鱼，空钩时可在水下直接切回鱼饵钩。玩家选择宝箱路线，主动调整收线 / 下潜，避开移动水母，使用冲刺吸附宝箱并短暂免疫碰撞。宝箱挂在钩上只算未结算货物，安全带回岸边才入账；断线会掉落本竿全部货物，原位置宝箱恢复，可再次尝试。鱼钩每竿三格耐久，碰撞有 1.6 秒保护期，归零后自动返航。基础鱼饵 / 活饵链保留在「鱼群狩猎」模式，空钩时可切换装备。

- 珊瑚浅滩：平静海流、两只巡游水母，默认开放。
- 沉船航道：横向海流、三只水母、沉船残骸背景，默认开放；鱼和宝箱售价 ×1.25。
- 幽蓝海沟：更强海流、四只水母，二级鱼线开放；售价 ×1.6。
- 每条航线有七个固定宝箱，航线间位置不同，共 21 个。每个已送达的宝箱独立记入存档；切换航线或刷新不会重复生成已领取宝箱。深层宝箱需要升级鱼线。
- 连续钓获逐次增加售价，每层 +15%，最高 +60%；空竿和断线中断连钓。切换海域不额外清空连钓。当前连钓在重载后重置，历史最高保留。
- 每第三次抛竿会触发 25 秒黄金鱼事件：一尾发光的太阳蓝鳃基础售价为普通鱼的三倍，可叠加海域与连钓倍率。
- 港口有三种可接取委托：安全送达两个宝箱（150 T）、带回三尾鱼（180 T）、接单后连续带回三尾鱼（240 T）。一次只追踪一张；重复接单不继承上一单进度，更换委托会重置当前进度，连钓委托也重置当前连钓数。目标完成自动发奖且只发一次。寻宝可重复接单，但每条海域宝箱为有限收藏，打捞完可切换捕获 / 连钓目标。

新增输入：E / 手柄 X /「冲刺」按钮执行冲刺（0.65 秒加速、0.8 秒保护、3.5 秒冷却），期间不触发鱼咬钩；↑ / W / 手柄上收线，↓ / S / 手柄下下潜。手机继续使用点按切换与左右按钮。持鱼冲刺时降低少量张力，大鱼会横向拉动钩子。

存档内容升级至 version 2，继续使用原有 localStorage key，自动迁移 version 1 的金币、装备、图鉴及待售渔获。新存档保存海域、已送达宝箱 ID、历史最高连钓、委托种类 / 进度 / 完成状态；货物、耐久、冲刺、当前连钓与限时事件属于本次出航状态。恢复时校验海域解锁、任务状态、ID 范围及包含倍率的合法鱼售价。港口 / 连钓 / 宝箱奖励仍为本地练习游戏币。

新增画面由 Canvas 绘制宝箱、移动水母、冲刺保护圈、货物挂钩、黄金鱼光环和沉船轮廓，沿用已有原创生成美术，无新增运行时依赖。

## 无法钓鱼修复

委托与装备已分离：接寻宝委托不会再禁止鱼咬钩。默认鱼饵钩，旧版存档缺少 `rig` 字段时恢复为鱼饵钩，同时保留金币、装备和所有委托进度；新存档单独记录装备选择。空钩时可在水下切换装备，无需先回岸。已上鱼或待处理渔获时禁止切换，避免绕过捕获结算。回归测试覆盖默认咬钩、寻宝委托不拦截咬钩、水下磁钩切换与旧存档兼容。
