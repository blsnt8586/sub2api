- `cavern.webp`：1440×900 矿洞背景；原图位于本地 `output/imagegen/token-miner/cavern-source.png`。

## 八关探险与随机矿况（2026-10-23）

- 单一八关流程，目标 650 / 1000 / 1350 / 1650 / 1900 / 2200 / 2500 / 2800 T；基础时限 60–95 秒，达到目标且矿物已回到地面后立即过关，不强制等待时间结束。
- 首关矿况稳定；之后每关随机稳定、富晶（晶体 +35%）、重矿（大矿 +30% 价值、+25% 重量）、松散（石头重量减半）。矿值有 ±10% 浮动，非石头有 12% 概率成为星标幸运矿，价值乘 1.7。
- 前七关过关后各选一次装备：卷扬每级回收速度 +22%，电池每级后续时限 +10 秒，鉴定仪每级后续晶体价值 +20%；每项最多三级。收益为乘法组合，装备不会重复影响已生成矿场。重试重新生成本关矿场，保留已获得装备及此前关卡积分。
- 每局探险使用同一个成绩 ID，累计分数更新同一记录，全部关卡完成才标记整局胜利。关卡进度会同步到 TOKEN 乐园服务端；积分和真实 API 余额分开管理。
- 关卡生成、碰撞、装备和计时全部在浏览器。测试包含多种随机种子下的八关正常出钩通关，不依赖服务器模拟。

## 当前规则：百关矿区挑战（2026-10-23，替代上方八关规则）

唯一探险包含 100 关 / 10 个矿区。`levels.ts` 定义每关目标、时限、摆钩速度、布局与晶体指标；五种布局分别是散矿、条带矿脉、深埋晶体、岩障和晶簇，叠加既有四种随机矿况。首关教学后难度逐步提高；第 10 / 20 / … / 100 关要求至少回收三块晶体，另有部分关卡要求两块。积分达标但晶体不足不会过关。每张矿场都校验总可回收价值至少达到目标的 1.28 倍，并保留可达、分离的矿物。

装备在第 10 / 20 / … / 90 关清关后各选一次，三项每项最多三级。100 关才为完整胜利；累计积分不能替代本关实际采矿。失败保持本关种子和之前装备，不能靠每次重试重抽一张更有利地图。

关间检查点按账号保存当前关卡、种子、此前积分和装备；浏览器 localStorage 用于快速恢复，同时异步同步到服务端，换浏览器或设备也能继续。已过的十关节点会重新显示一次升级选择，选择后立刻写入下一关，避免升级重复叠加。存档和积分均不直接授权 API 额度，真实奖励由服务端单独校验。

参考规则与可核实的百层魔塔来源见 `docs/token-park-long-campaign-research.md`。本次使用既有原创美术，无第三方代码或图像拷贝。
