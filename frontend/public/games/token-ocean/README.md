# TOKEN 大鱼吃小鱼

原生 Canvas 2D 动作小游戏，无 Unity / Three.js / 外部运行时。入口 `/arcade/ocean`，作为 TOKEN 乐园三款正式游戏之一。

- 鼠标移动、手指拖动、WASD / 方向键或标准手柄左摇杆连续游动。空格 / E / 手柄 A / 屏幕按钮冲刺，P / 菜单暂停，Esc 退出沉浸并暂停。
- 体型超过对方 15% 才能吞食；相近体型互不伤害。大鱼追逐，小鱼逃跑，进化后旧敌人可以成为猎物。
- 六种形态，成长质量阈值 0 / 35 / 105 / 240 / 480 / 850；轻松模式到达最终形态完成本局并奖励练习分数。三次受伤结束，有短暂受伤保护；冲刺期间不受捕食伤害。
- 3.4 秒连吃窗口，连吃倍率最高五倍；八连吃触发 4.5 秒狂暴加速。黄金鱼三倍分数、双倍成长；冲刺消耗 38 体力，体力自动恢复。
- 摄像机跟随、鱼尾分段动画、吞食粒子、分数浮字、进化闪光。减少动态效果偏好会关闭镜头抖动 / 闪光及鱼尾等装饰动画。
- 切后台、失焦、滚动离屏自动暂停；恢复时清除旧输入。图像失败可重试；Canvas 在暂停时收到尺寸变化也会重绘。页面退出清理 RAF、观察器与事件。
- 本局记录按账号隔离，按局 ID 去重；关卡进度会保存到 TOKEN 乐园服务端，结束或离开时记录本次练习得分。

美术复用 `../token-fishing/cove.webp` 的水下部分及六种原创生成透明鱼类 WebP。来源和提示词在该目录 README 与 prompts 中。`../library/ocean.webp` 使用相同海湾水下裁切并叠加鱼类精灵合成，未使用商业游戏素材，也无运行时凭据。原有素材无需重复打包；新增海洋生物素材在本目录。

## 猎手挑战（2026-10-21）

开始面板可选择「猎手挑战」或「轻松开吃」，默认挑战；键盘左右键 / 手柄左右也能切换，重开保留所选模式。挑战模式开局保持快速进化的反馈，后续成长放慢。

- 六秒后出现限时黄金鱼潮：11–14 秒内吃光六尾黄金鱼，额外奖励 500 分并恢复一格生命（最多三格）。鱼群受惊逃开后重新聚群，超时清除该鱼群，不奖励未完成的整群挑战；超时后下一次间隔 14–26 秒，成功清群后间隔 16 秒。
- 十八秒后猎手出现，依次巡游、预瞄、锁定路线、冲锋、疲惫。预瞄最后半秒不会改变目标，冲锋不追踪转弯；路线、锁定目标、尾部发光标记和屏幕边缘方向提示均可见。
- 疲惫窗口可冲刺咬尾，普通阶段奖励 300 分和 18 成长质量；一次疲惫只结算一次。惊险擦身躲开冲锋奖励 120 分。冲刺保护和受伤保护继续有效。
- 完成三海域狩猎目标并满成长后进入单独的猎手决战，普通捕食鱼退场，只补充可吞食的背景鱼。猎手每次冲锋后有 3.6 秒疲惫窗口，冲刺咬尾三次才能获胜；每次 750 分、最终 2000 分。尾部旁显示剩余反击秒数。
- 星级：完成挑战一星；8 分钟内通关再一星；至少剩两命且惊险闪避与咬尾合计至少五次，再一星。结果页显示用时 / 闪避 / 咬尾次数及规则。
- 横屏摄像机在限制最大可见宽度时同步调整可见高度，保持鱼体与预警路线的比例。

参考资料、来源能证明的规则及本项目的原创设计区分见 `docs/token-ocean-gameplay-research.md`。新增的状态机、奖励唯一性、时限、成长 / 最终通关、星级、模式切换与输入生命周期有测试覆盖。此模式不增加新的收费或账户额度语义。

## 吞食手感与画面精修（2026-10-21）

- 移除玩家 / 普通捕食鱼 / 黄金鱼 / 猎手的描边圈、护盾圆盘、鱼群范围椭圆及瞄准圆；鱼群不再挂满「可吞食」文字。玩家用小箭头辨认，黄金鱼用星光，临近危险用小警示，猎手用淡光带预告冲锋、菱形提示尾部弱点。
- 鱼群成队游动，开局两组鱼群，之后补充成群目标。冲刺吸入口前的近距离小鱼，连吞更容易形成一次路线选择；没有新增操作键。
- 吞食后显示 0.22 秒缩入动画、鱼身回弹、合并的得分浮字，以及 0.55 秒窗口内的连吞反馈。视觉对象有数量限制，暂停和减少动态效果偏好仍生效。
- 连吃八条触发 4.5 秒狂暴，可反吃体型不超过自身 1.6 倍的普通鱼，原本危险的猎物计双倍分；猎手继续按原规则反击。狂暴结束恢复体型判定。
- 场景镜头略微拉近，增加水下光束 / 浮游颗粒 / 暗角和顺应方向的鱼体倾斜。HUD 改成轻量文字与小控件，手机沉浸模式单独安排狂暴提示。
- 增加可开关的合成吞食 / 冲刺 / 进化 / 受伤短音效，默认静音。仅在用户点击开启后创建 AudioContext，音频不可用仍可游玩，退出释放音频资源。无外部音频下载。


## 珊瑚海生物与递增难度（2026-10-21）

- 六种成长形态之外增加小丑鱼、蝴蝶鱼、沙丁鱼、河豚、狮子鱼、梭鱼、锤头鲨、鮟鱇，共 14 种生物；河豚独立提供普通 / 鼓起两张图。`species.ts` 管理全部素材路径，与玩家进化路线分开。锤头鲨取代旧蓝鳍贴图担任猎手。
- 新素材通过用户授权的已配置 API 调用 imagegen bundled CLI / `gpt-image-2` 生成，图集 1536×1536，统一手绘风格；提示词见 `prompts/reef-species.txt`，源图 `output/imagegen/token-ocean/reef-species.png`，发布仅使用裁切透明 WebP，无运行时网络请求。素材检索 / 取舍见玩法参考文档。
- 沙丁鱼受惊逃跑速度 158，吞食恢复 16 冲刺体力（不超过 100）；小丑鱼 / 蝴蝶鱼加入成队游动目标。
- 河豚 8 秒周期：4–4.8 秒预警，4.8–7.2 秒鼓起，其他时间正常。鼓起时接触体积 ×1.45，任何体型和狂暴都不能吞，冲刺仍可安全穿过；收刺后按普通体型规则吃，双倍分。
- 狮子鱼普通状态即使体型小也有毒；狂暴期间可在 1.6 倍体型限制内反吃，双倍分。河豚 / 毒鳍不会被随机标记成黄金鱼，危险的碰撞优先于同帧吞食进化结算。
- 挑战模式梭鱼接近时预瞄 0.9 秒，末 0.45 秒锁定；沿固定方向以 390 速度冲锋 0.7 秒，之后恢复 1.5 秒，禁止中途追踪转弯。鮟鱇只在 210 距离内开始追逐，追击速度更快。
- 初始 78 次随机投放 + 两组 5 尾开场鱼。普通鱼群数量目标按警戒为 88 / 98 / 108，黄金鱼事件临时最多增加 6。每 5 秒尝试补充成队目标；仅回收距玩家超过 1150 的非事件鱼，避免世界已满时不再刷新新种类，也不让可见鱼突然消失。
- 挑战模式进化到第 3 阶段或 35 秒进入警戒 II；第 5 阶段或 70 秒进入警戒 III。捕食者占比、追击距离、游速递增；猎手普通预瞄 1.5 / 1.35 / 1.2 秒，始终保留最后 0.5 秒锁定路线，追击速度 510 / 550 / 590，疲惫窗口 2.8 / 2.55 / 2.3 秒。普通冲刺体力回复由 23 调整至 19 / 秒，可通过沙丁鱼补充；轻松模式维持原回复与普通捕食节奏。
- 最终决战清除河豚、狮子鱼以及体型不满足普通吞食条件的鱼，狂暴不会误留会在结束后变回危险的鱼。继续保留 3.6 秒反击窗口和三次尾部打击。
- 游戏下方增加可展开图鉴；场内仅在近距离显示收刺 / 毒鳍 / 突袭提示，没有加回选中圈、鱼体拖尾或速度线。警戒指示在决战时替换为决战状态。

### 密度增加后的平衡校正

浏览器首轮实测发现，提高鱼群密度会使连续狂暴 / 进化保护过于密集。挑战模式现在首阶成长不变，之后吞食成长系数从 0.5 降至 0.34；进化保护由 1.8 秒降至 0.65 秒；狂暴仍持续 4.5 秒，但结束后有 6 秒冷却，期间不累计狂暴能量，HUD 显示剩余冷却。轻松模式保留原进化保护和无冷却狂暴。相关回归测试保证狂暴间存在可受伤窗口。

## 深海远征（2026-10-21）

- 开场面板新增「深海远征」，与「猎手挑战」「轻松开吃」并列；远征不在最终形态自动结束，可以继续下潜、发现生物和积累练习分。
- 海域按深度分为日光浅礁、暮光水域、幽蓝深渊。远征 HUD 显示当前深度 / 水层、图鉴发现数和遗物进度；离开远征时保留本局结果，不改变账户余额或额度。
- 增加灯笼鱼、斧头鱼、蝰鱼、吞鳗、皇带鱼、蝠鲼、大王乌贼、鲸鲨、蓝鲸九种深海生物，图鉴总数为 23。深海猎食鱼只在合适水层出现，避免浅层随机刷出无法理解的危险。
- 蝠鲼、鲸鲨、蓝鲸和皇带鱼属于温和巨兽：体型巨大、不会主动攻击，也不能被吞食。开局 12 秒后按玩家所在水层出现蝠鲼、鲸鲨或蓝鲸伴游事件，路线出现六枚光晶；18 秒内收集完成后恢复生命并获得额外分数，超时只结束事件，不发放整组奖励。
- 九种深海生物与独立深渊背景通过已配置的图像 API 生成，提示词见 `prompts/abyss-species.txt` 和 `prompts/abyss-scene.txt`，源图在忽略目录 `output/imagegen/token-ocean/`；本目录发布透明鱼类 WebP 与压缩背景，不包含 API 凭据。
- 三枚深海遗物按水层放置，收集每枚恢复体力并奖励分数，集齐后再发一次完成奖励和生命。遗物、光晶和生物发现均只结算一次。
- 移动端 / 横屏开场模式按钮使用稳定三列布局，说明文字在窄屏保持可读；深渊背景、巨兽和鱼类均使用同一套原创位图素材，不依赖 Unity、Three.js 或运行时网络资源。
- 巨兽放大检查后，鱼体改为整图轻摆、起伏与吞食缩放，替代旧分片摆尾，消除大鱼身上的竖直接缝和重影。

## 三海域狩猎与随机鱼潮（2026-10-23）

- 挑战模式按浅礁 → 暮光 → 深渊完成三段目标。每段开局随机决定普通吞食或冲刺吞食及数量：普通目标为 26–32 / 36–42 / 46–52，冲刺目标为 16–22 / 22–28 / 28–34。捕获位置决定所属水层，完成前一段后才会累计下一段。
- 每段一次奖励 800 / 1000 / 1200 练习分、恢复一格生命并回满体力。三段都完成且成长达到最终形态，才开启原有三次反击的猎手决战。目标由单局种子确定，推进和重开不复用旧计数。
- 挑战与无尽远征均有随机丰饶鱼潮、流金鱼潮、顺流窗口。首事件在 22–34 秒，持续 14–20 秒，结束后再等待 18–34 秒；不连续重复同一种事件。丰饶鱼潮带来新鱼群并缩短补群间隔；流金提高黄金鱼出现率（9% → 32%）；顺流提升 18% 游速及体力恢复（36/秒）。新鱼群远离玩家生成，最终决战清除事件效果。
- 区域目标和当前事件在既有底部 HUD 内展示；轻松模式保留原来的进化通关，无尽远征继续不设结束时限。暂停不推进目标、事件和倒计时，重开清空全部本局状态。
- 玩法均在浏览器运行，不增加游戏服务端、积分兑换接口、排行榜或余额发放。

## 当前规则：唯一六十关挑战（2026-10-23，替代上方多模式与三段规则）

- 游戏只有一种玩法，删除轻松 / 无尽远征入口及引擎 mode 分支。深海生物、图鉴、遗物、伴游和随机鱼潮作为挑战中的事件保留。
- `campaign.ts` 定义 60 关 / 10 轮，每轮六关，依次在浅礁、暮光、深渊进行，任务在吞食、冲刺吞食、黄金鱼间变化，具体数量有单局种子浮动。每六关的最后一关完成捕猎目标并满成长后触发猎手，反击三次只完成这一关；第 60 关才是整场胜利。
- 每关从适合其轮内位置的成长形态开始，逐轮目标提高、时限收紧，首领冲锋逐轮加速；时间用尽或生命耗尽失败。进入下一关恢复一命（最多三），保留累计积分，重置本关任务与计时。连续关卡事件按新关起点安排，不会因上一关累计时间立即触发全部事件。
- 本地检查点 `token-park-ocean-campaign-v1:<userId>` 按账号隔离，保存当前关起点或关间结算，刷新从本关开始，不保存每条鱼的中途状态；重试只重试本关，丢弃失败关积分，不会重复叠加关卡奖励。存储受限仍可游戏，清除浏览器数据会丢失进度。
- 积分和检查点仅供娱乐。客户端数据没有防篡改保证，不作为真实额度、奖池或排行榜的服务端凭据。
