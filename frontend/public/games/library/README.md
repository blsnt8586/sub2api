# TOKEN 乐园游戏库美术

游戏封面与大厅大图使用本地 WebP，运行时无需图像 API、密钥或第三方图片服务。

| 文件 | 来源 | 尺寸 | 大小 |
| --- | --- | --- | --- |
| `miner.webp` | 从同仓库 `../token-miner/` 已生成的矿洞、机器人、金币和晶体素材合成 | 1440 × 900 | 199302 bytes |

矿工原始素材的提示词见 [矿工素材目录](../token-miner/README.md)。生成原图保留在本地忽略目录 `output/imagegen/library/`，不进入前端发布包。

矿工、海洋和魔塔使用本地原创素材，目录按动作、冒险和休闲分类展示。

封面上的游戏名称、类型和操作按钮均由页面渲染，便于国际化和适配手机。大厅保留站点浅色 / 深色主题，沉浸模式采用深色主机界面。游戏目录由 `src/games/catalog.ts` 管理，只有可实际游玩的条目才进入游戏库。

大厅操作：左右方向键切换游戏，上方向键进入筛选，下方向键回到游戏卡片，Enter / Space 激活聚焦按钮；F 切换沉浸模式，Esc 退出。标准映射手柄支持方向键 / 左摇杆、A 确认、B 返回、菜单键切换模式。

TOKEN 乐园当前提供 TOKEN 矿工、TOKEN 海洋和 TOKEN 魔塔三款游戏。

大厅分数为本次登录会话内的练习记录；三款游戏的正式关卡进度由服务端按账号保存，和 API 额度、奖励领取记录分开管理。
